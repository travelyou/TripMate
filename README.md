## TripMate 專案簡介

**[TripMate](https://tripmate-mayoyo.com/) 是一個智慧旅遊社群平台，解決旅行者最核心的問題：找到志同道合的旅伴。**

![TripMate Logo](./src/assets/pic/loginPage-removebg.png)

透過整合社群互動、行程規劃、旅伴配對與 AI 助手，為使用者提供一站式的旅遊體驗。

- **身為「旅行愛好者」**：想找旅伴，卻不知道如何找到合適的人？
- **面對「行程規劃」**：想規劃完美行程，但缺乏個人化？
- **每次都在猶豫**：「這個旅伴適合我嗎？會不會個性不合？」

## TripMate 使用方式

### 透過 [TripMate](https://tripmate-mayoyo.com/)，你只需要：

1. **註冊帳號並完成性格測驗**
2. **瀏覽精選行程或創建自己的行程**
3. **使用智慧配對找到適合的旅伴**
4. **透過私訊討論旅行計畫**
5. **參與社群分享旅遊經驗**

## TripMate 提供

### 解決的痛點

- **找不到旅伴?**   透過性格配對系統，找到真正適合的旅行夥伴
- **行程規劃困難?**   AI 助手提供客製化建議，輕鬆規劃完美行程
- **資訊分散?**   一站式平台整合社群、規劃、交友、購物等功能

### 核心功能

- **智慧旅伴配對**：透過性格測驗與演算法，精準推薦最適合的旅伴
- **行程規劃管理**：建立專屬旅遊護照、編輯個人行程，支援草稿保存與分享
- **社群互動平台**：發布貼文、參與討論、尋找旅伴
- **AI 智慧助手**：基於 Google Gemini 的個人化行程建議
- **旅遊行程購物**：完整的購物車、結帳與訂單管理
- **廠商管理平台**：專屬的商家後台與行程上架功能
